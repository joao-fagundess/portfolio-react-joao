# Portfólio React — João Pedro Flor

Projeto de portfólio profissional desenvolvido com React + Vite, HTML e CSS.

## Requisitos
- Node.js instalado
- Git instalado (para publicar no GitHub)

## Executar localmente
1. Extraia a pasta do projeto.
2. Abra a pasta no VS Code.
3. Abra o terminal do VS Code.
4. Execute:

```bash
npm install
npm run dev
```

5. Abra no navegador o endereço local exibido no terminal.

## Gerar versão de produção
```bash
npm run build
```

## Publicar no GitHub e Vercel
1. Crie um repositório público no GitHub chamado `portfolio-react-joao`.
2. Envie todos os arquivos desta pasta para o repositório (não envie `node_modules`).
3. Entre em https://vercel.com/ e faça login com GitHub.
4. Clique em **Add New → Project** e importe `portfolio-react-joao`.
5. Mantenha as configurações detectadas pelo Vercel (Vite); clique em **Deploy**.
6. Ao terminar, copie o endereço público `.vercel.app` para entregar no Teams.
